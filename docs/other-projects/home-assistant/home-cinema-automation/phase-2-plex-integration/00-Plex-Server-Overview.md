## Objective

Integrate Plex Media Server into Home Assistant to provide media information for the Home Cinema Automation project.

## Server Location

Dad's laptop

## Purpose

The Plex server acts as the media source for:

- Cinema Mode dashboard
- Now Showing screen
- Movie Night automation
- Recently Added movies
- Media metadata

## Future Consumers

- Hallway display
- Cinema room tablet
- Office tablet
- Kitchen tablet
