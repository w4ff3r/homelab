# Home Cinema Automation

A Home Assistant-powered home cinema companion designed to emulate a real theatre experience.

## Features

- Plex integration
- Automatic "Now Showing" display
- Family photo idle mode
- Movie Night automation
- Touchscreen support
- Future smart lighting integration

## Technologies

- Home Assistant OS
- VMware Workstation Pro
- Plex
- Raspberry Pi / Home Assistant Green
- YAML
- Dashboard Design
- Home Automation
