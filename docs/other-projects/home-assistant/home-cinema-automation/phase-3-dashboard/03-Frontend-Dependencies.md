## Objective

Community plugins installed through HACS to improve the dashboard user experience.

---

## Installed Components

### Card Mod

Purpose:

Provides advanced styling through CSS modifications.

Used for:

- Cinema styling
- Shadows
- Colours
- Border removal

---

### Mushroom Cards

Purpose:

Modern dashboard components.

Used for:

- Navigation
- Home dashboard
- Buttons

---

### Button Card

Purpose:

Highly configurable dashboard cards.

Used for:

- Movie cards
- Interactive controls
- Dynamic layouts

---

### Kiosk Mode

Purpose:

Removes standard Home Assistant navigation.

Used for:

- Permanent hallway display

---

### Swipe Card

Purpose:

Creates swipeable collections of cards.

Planned Uses:

- Family photos
- Recently added movies
- Favourite movies
