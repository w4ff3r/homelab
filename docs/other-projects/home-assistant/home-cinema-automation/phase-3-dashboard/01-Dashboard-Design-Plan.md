## Objective

Design a permanent portrait dashboard for the hallway display that serves both as a home information hub and a home cinema companion.

The display is intended to remain active throughout the day and transition between multiple operating modes depending on user interaction and automation triggers.

---

## Design Philosophy

The display should function as a digital feature within the home rather than simply acting as a monitor.

The dashboard should provide useful information during everyday use while transforming into a cinema-style display during movie playback.

---

## Primary Goals

- Display family information during normal operation.
- Provide a central navigation hub.
- Display current Plex playback information.
- Support future touchscreen interaction.
- Operate continuously with scheduled display sleep periods.

---

## Dashboard States

### Family Screensaver

Default display showing:

- Family photos
- Clock
- Weather
- Calendar events

---

### Home Dashboard

Navigation hub providing access to:

- Movie Night
- Calendar
- Shopping List
- Photos
- Settings

---

### Cinema Idle

Displayed before playback begins.

Features include:

- Favourite movies
- Recently added content
- Ready for Movie Night prompt

---

### Now Showing

Displayed during Plex playback.

Features include:

- Movie poster
- Title
- Runtime
- Classification
- Synopsis
- Playback status

---
